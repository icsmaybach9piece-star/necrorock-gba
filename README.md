# NECROROCK GBA

A biomechanical horror Metroidvania for the Game Boy Advance.

## Target Hardware

Nintendo Game Boy Advance

Resolution: 240x160

CPU: ARM7TDMI

## Build

GitHub Actions automatically builds the ROM.

The resulting file is:

NECROROCK.gba

## Status

Early prototype.

Planned features:

- Metroidvania exploration
- Iggy Pop protagonist
- Biomechanical alien environments
- Horror enemies
- Cosmic bosses
- Exploration abilities
- Combat
- Inventory
- Save system
- Original soundtrack
- Multiple areas
- Boss encounters
